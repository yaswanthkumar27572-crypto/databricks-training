# Day 1: SQL Fundamentals & Data Retrieval

## Overview
Today's session focused on establishing a strong foundation in SQL, moving from basic data selection to complex filtering and aggregate functions. All queries were practiced using DB Fiddle and verified against the provided training schema.

## Key Learnings
- Basic Retrieval : Mastered `SELECT`, `FROM`, and column aliasing.
- Filtering Data : Used `WHERE` clauses with comparison operators (`>`, `<`, `=`).
- Pattern Matching : Implemented `LIKE` with wildcards (`%` for multiple chars, `_` for single char).
- Date Functions : Extracted parts of dates using `YEAR()`, `MONTH()`, and `DAYNAME()`.
- Logical Operators : Combined conditions using `AND`, `OR`, `IN`, and `BETWEEN`.
- Aggregations & Sorting : Utilized `COUNT`, `SUM`, `AVG`, and `ORDER BY` to organize data.

## Tools Used
- DB Fiddle : For query execution and schema testing.
- GitHub : For version control and documentation management.
